# Touchpad camera look (virtual right stick)

## User-facing behavior

- The in-game overlay menu retains the **Mouse control: ON/OFF** setting for compatibility.
- The setting is persisted in `gamepad_overlay/mouse_control_enabled`.
- When ON, a finger that starts outside every virtual gamepad hitbox controls camera look through the virtual Xbox RIGHT STICK.
- Finger movement is interpreted as stick velocity: horizontal/vertical deltas become analog X/Y values, clamped to the XInput range.
- The virtual right-stick axes return to zero 45 ms after the last movement and immediately when the touch ends.
- Enabling Mouse control opens the camera-look settings dialog. The overlay menu also exposes a separate settings entry while enabled.
- Sensitivity, speed, vertical sensitivity and vertical inversion are persisted in `gamepad_overlay` preferences.
- Sensitivity and speed multiply the horizontal response; vertical sensitivity independently scales Y. The visible physical right-stick control remains unchanged.
- A finger that starts on a visible virtual control remains owned by that control for its whole gesture.
- If the physical on-screen RS control is being held, it has priority over the trackpad.
- The normal gamepad buttons, triggers, left stick and right-stick control remain available.

## Input routing

The touch overlay follows the same broad architecture as `doom-port`'s Android touch controls: touch events are translated into gamepad axis state, rather than synthesized as mouse events. In Skyrim, `GamepadOverlayView` submits the virtual RIGHT STICK X/Y values through the existing `nativeSetVirtualPad` callback. The normal virtual XInput controller path then delivers those values to the game.

No SDL mouse motion or mouse button events are generated by the touchpad. This avoids dependence on SDL relative-mouse mode and the game's mouse event handling.

## Device validation checklist

1. Enable **Mouse control** in the in-game overlay menu.
2. Swipe on empty screen space; verify the camera rotates left/right and up/down.
3. Stop moving; verify the camera stops within approximately 45 ms.
4. Repeat with short, slow and fast swipes.
5. Hold a virtual gamepad button while swiping; verify both inputs work simultaneously.
6. Touch and drag the visible RS control; verify it retains priority and behaves as a normal analog stick.
7. Disable Mouse control; empty-space touches must no longer rotate the camera.
8. Repeat in X11 and Wayland launch modes.

## Implementation tuning

`trackpadSensitivity` defaults to 1.6 (range 0.25–4.0), `trackpadSpeed` defaults to 1.0 (range 0.25–3.0), and vertical scale defaults to 1.0 (range 0.25–3.0). These values are editable in the in-game Mouse control settings dialog. Stick deflection is normalized against 6% of the smaller overlay dimension and clamped to [-32767, 32767]. The vertical inversion option changes only the touchpad Y direction.
