## GPU cost

At 2448x1080 the 75% grid has 5,600 cells. Sampled total-chain values range roughly from 11.9 ms to above 21 ms in this upload. Both flow directions dominate the chain; luma and midpoint warp are smaller but non-trivial. The initial samples are slower than later samples, so this file alone cannot establish a stable median or thermal throttling. GPU timestamps should be treated as instrumented chain cost, not whole-game frame time.

The present flow search evaluates 89 candidate positions per cell, each with a 3x3 SAD patch, in both directions. Increasing the search radius by brute force would materially raise GPU work. The next search improvement should be pyramid/coarse-to-fine rather than simply multiplying the candidate count.

## Source correction after this test

`midpoint_warp.comp` previously used a 50/50 unwarped blend as its low-confidence fallback. When the motion field is weak, this overlays two displaced camera views and visibly blurs edges even if it avoids geometric bending.

The fallback is now the current real frame, not an average of the two unwarped frames. Reliable regions still use the bidirectional warped midpoint. Ambiguous regions remain spatially sharp but may temporarily behave like a duplicated real frame (less local temporal smoothness). This is a deliberate quality-first fallback until motion estimation is improved.

This is a source change only. Shader validation, native build, APK build and device verification are still required.
